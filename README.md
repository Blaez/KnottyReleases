# Knotty

Knotty is a unofficial e621 Android app for browsing e621.

There were a handful of E621 apps but what really inspired me was Yiffer by EchoTiger, Thanks for making such a great app!

Built for people who just want a chill app experience and notifications for pools.

### Offline & Local Data

- Offline cache for search results
- Offline cache for favorites
- Cached post metadata
- Previously loaded pages can reopen without internet
- Viewed-post tracking
- download history

### Backup & Restore

Knotty can export and restore your app data as a JSON backup.

Backups will include:

- Settings
- Tabs
- Search History
- Viewed posts
- Subscriptions
- Download history
- Login

> Heads up: backups WILL include your API key, so treat backup files like passwords.

### App Lock

Knotty can be locked behind:

- Fingerprint
- Face unlock
- Whatever you useto unlock your screen

Nice for keeping people OUT.
