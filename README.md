## What Knotty Can Do

### Search & Browsing

- Search e621 posts from inside the app(obviously)
- Multi-tab search, so you can keep different searches open
- Infinite scrolling
- Tag autocomplete while typing
- A search builder for common filters like order:score
- Search history
- Undo and redo for recent searches
- Flow grid and vertical feed layouts
- Viewed-post indicators so you know what you've opened

### Post Viewer

- Open posts in a detail page
- Swipe left and right between posts including in fullscreen(Perfect for pools)
- Fullscreen media viewer
- Pinch zoom, panning, and double-tap zoom
- Preloads nearby posts so swiping feels smoother
- Shows post descriptions
- Shows parent and child posts
- Shows pool membership when a post belongs to pools
- Smooth transitions from thumbnails to detail view

### Media Support

- Images
- Autoplaying GIFs
- Videos with WebM / MP4 playback
- Save media to gallery
- Download manager with active, completed, and failed downloads
- Batch downloads
- Full pool downloads

### Favorites, Votes, and Account Stuff

- Login with e621 API key
- API key is stored securely with encryption
- Favorite and unfavorite posts
- Upvote and downvote posts
- Upvote and downvote comments
- Better syncing with votes made on the website

### Tags & Filtering

- Rating filters for Safe, Questionable, and Explicit content
- Custom tag blacklist
- Long-press tags to quickly add them to the blacklist
- Tag category coloring
- Tag sorting by importance:
  - Artists
  - Characters
  - Species
  - Copyright
  - General / Meta

### Pools, Sets, and Explore

- Browse pools and user sets
- Open pools and sets as their own tabs
- Pool cover thumbnails
- Pool subscription support
- Pool rows on post details can open the pool directly

### Subscriptions

Knotty can watch tag searches and pools for new posts.

You can:

- Subscribe to tag searches
- Subscribe to pool IDs / comics
- Manually add subscriptions
- On demand checks
- Get notified when newer matching posts are found
- Manage subscriptions

### Knotty Wrapped

Knotty has a Wrapped-style stats screen for your favorites and viewed posts.

It can show things like:

- Top tags
- Top artists
- Top species
- Top characters
- Rating breakdowns
- File types
- Highest-score favorite
- Monthly viewed stats

Basically, it tells you what your taste looks like.  
Good luck with that information...you'll probably need it

### Offline & Local Data

- Offline cache for search results
- Offline cache for favorites
- Cached post metadata
- Previously loaded pages can reopen without internet
- Viewed-post tracking
- download history

### Backup & Restore

Knotty can export and restore your app data as a JSON backup.

Backups can include:

- Settings
- Tabs
- History
- Viewed posts
- Subscriptions
- Downloads
- Login fields

> Heads up: backups may include your API key, so treat backup files like passwords.

### App Lock

Knotty can be locked behind:

- Fingerprint
- Face unlock
- Whatever you useto unlock your screen

Nice for keeping people OUT.

### Updates

- Built-in update checker
- Release notes in-app
